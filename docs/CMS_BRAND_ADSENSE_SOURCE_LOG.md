### CMS decision

Use hosted Pages CMS as an external authenticated editor over `src/content/articles/` and repository-tracked, non-deployed source media in `src/content-assets/articles/`. Every committed file and branch is publicly visible; confidential evidence stays outside Git. The validated build publishes only referenced media to public URLs under `/images/articles/`. Add no public `/admin` or `/keystatic` surface. Hosted authorization and a save round-trip remain owner actions, not completed claims.

### Visual decision

Select **Signal Rail**, implemented as Balanced Purple Signal / Editorial Rail / Evidence-first Reading: approximately 70% light editorial surface and 30% dark or high-energy technology surface. The two alternatives—dark-dominant Night Dispatch and light-dominant Lavender Ledger—remain in `.planning/sketches/` as rejected reference points.

### Internal monetization controls

Only `off` is an implemented internal mode in this release; it is not Google product terminology. It permits no script, publisher/meta ID, request, slot, blank gap, `ads.txt`, or advertising CMP.

`verification` and `live` remain future workflow labels, not accepted code states. They require a separately reviewed end-to-end implementation after the owner supplies genuine account evidence and explicitly authorizes the exact change. This avoids shipping dormant advertising code or accepting a configuration that the build, CSP, consent model, and production checks cannot fully execute.

The site design, article count, CMS, custom domain, metadata, or QA results cannot guarantee AdSense approval. Google alone decides.
