# Sketch 002: Story Hierarchy

## Design Question

Which arrangement makes guide purpose, time, topic, and concrete output easiest to scan without rendering every item as the same rounded card?

## How to View

Open `.planning/sketches/002-story-hierarchy/index.html`.

## Variants

- **A: Editorial Rail — selected** — Typographic rows, explicit guide promises, and restrained separators.
- **B: Magazine Mosaic** — More visual diversity, but more hierarchy than a 15-guide library currently needs.
- **C: Report Grid** — Extremely systematic, but too close to a documentation portal.

## What to Look For

Compare scan speed, duplication, clarity of deliverables, topic discovery, and the balance between illustration and typography.

## Decision

Variant A is selected because it explains each guide fastest, preserves the complete archive, and avoids a repetitive card wall.
